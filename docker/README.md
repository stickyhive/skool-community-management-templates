# Skool Community Management Templates

A lightweight Docker container that serves free Skool community management templates as a local browsable resource site.

Includes onboarding checklists, DM sequences, content calendars, member reactivation workflows, churn prevention systems, and engagement plans for Skool community owners.

## Quick Start

```bash
docker run -p 8080:80 stickyhive/skool-community-templates
```

Then open http://localhost:8080 to browse all templates.

## What's Included

### Templates
- **Skool Onboarding Checklist** — Step-by-step new member welcome process
- **Skool DM Sequence Template** — 5-message sequence (Day 0 → Day 30)
- **Skool Content Calendar** — Weekly posting schedule for engagement
- **Member Reactivation Template** — Messages for re-engaging inactive members
- **Weekly Digest Template** — Community highlights post format

### Workflows
- **New Member Welcome Workflow** — End-to-end onboarding process
- **Inactive Member Rescue Workflow** — System for rescuing disengaging members
- **Trial Member Conversion Workflow** — Free-to-paid conversion process
- **Churn Risk Alert Workflow** — Early warning system for at-risk members

### Examples
- **30-Day Engagement Plan** — Full month of community engagement activities
- **7-Day Activation Plan** — First-week member activation sequence
- **Community Health Score** — Framework for measuring community health

## Use Cases

- Run locally as a reference while managing your Skool community
- Self-host on your server as a team resource
- Use as a starting point for your own community management docs

## Automating These Workflows

These templates can be run manually. If you want to automate DM sequences, schedule posts, monitor member health, and prevent churn automatically, [StickyHive](https://stickyhive.ai) is a Skool community management tool built for this.
